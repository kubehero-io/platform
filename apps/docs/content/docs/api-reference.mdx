The `.proto` files in [`packages/proto/kubehero/v1`](https://github.com/kubehero-io/platform/tree/main/packages/proto/kubehero/v1) are the source of truth. The same contracts generate the Go servers, the TypeScript client the dashboard uses and the CLI's client.

## Calling the API

Every RPC is served by [Connect](https://connectrpc.com/) over HTTP/1.1 or HTTP/2, so gRPC tools, generated clients and plain `curl` with JSON all work:

```bash
curl -s -X POST "$KUBEHERO_ENDPOINT/kubehero.v1.CostService/GetAllocation" \
  -H "Authorization: Bearer $KUBEHERO_TOKEN" -H "Content-Type: application/json" \
  -d '{"window":"24h","aggregate":["namespace"]}'
```

JSON follows protobuf's canonical mapping: `lowerCamelCase` field names, 64-bit integers as strings, zero values omitted.

**Auth.** `Authorization: Bearer <token>` — an API key, a per-cluster token or an OIDC ID token. Roles: `viewer` < `member` < `admin` < `owner`, plus `auditor` (read everything, including the audit log). Reads need `viewer`, ingest needs `member`, mutations need `admin`. `WhoAmI` returns the resolved caller. See [Identity](/docs/integrations/identity).

**Demo data.** When a signal's store isn't configured, responses carry `source: "demo"`. With `KUBEHERO_DEMO_MODE=false` those RPCs return `failed_precondition` instead.

### Ingest limits

`TelemetryService` requests are validated and bounded: up to 10,000 log entries, 5,000 flows, 2,000 profiles or 20,000 stack samples per request; log lines over 64 KiB are truncated and marked; timestamps more than 10 minutes in the future are rejected. Every call returns `accepted` and `dropped` counts; rejected rows are never retried. When an ingest queue is full the RPC returns `resource_exhausted` — back off and retry.

### Query limits

`QueryLogs` returns at most 5,000 lines (100 by default) and defaults to the last hour. `GetFlamegraph` prunes to `max_nodes` (2,048 by default). `GetServiceMap` keeps the busiest `max_nodes` (60) and folds the rest into `other`. Alert queries are capped at 4,096 characters, 20 matchers and 24h ranges.

## Errors

Standard Connect codes:

| Code | Meaning |
|---|---|
| `unauthenticated` | missing or invalid token |
| `permission_denied` | the token's role can't do this |
| `invalid_argument` | malformed request — e.g. a LogQL parse error (with position), an unknown aggregate, a range too long |
| `not_found` | unknown cluster, policy, rule or SKU |
| `failed_precondition` | the store behind this RPC isn't configured and demo mode is off |
| `resource_exhausted` | an ingest queue is full — retry with backoff |

## Versioning

Contracts live under `kubehero/v1`. Changes within `v1` are additive; a breaking change would ship as `v2` alongside `v1` for at least one minor release.
