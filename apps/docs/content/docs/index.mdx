KubeHero is **one open-source install** for cost allocation, logs, continuous profiling, eBPF network cost, alerting and rightsizing that actually adjusts — with read-only agents that connect every signal to the dollar it costs. It runs in your cluster; nothing leaves it.

```bash
helm install kubehero oci://ghcr.io/kubehero-io/charts/kubehero \
  -n kubehero-system --create-namespace
```
